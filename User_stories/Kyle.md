##Story

As support staff, I need to be able to be able to easily update student-facing data, so I can do my job efficiently and help students.

##Acceptance criteria:

Given I am updating multiple student timetables, when I upload the data, the upload is easy to do.

Given I am updating multiple student timetables, when I spot mistakes or need to commit changes, I can edit portions quickly in app

Given I have uploaded a timetable, when I go to check it has been successful, I can see when it was last updated without reading through all entries.

Given I have uploaded a timetable correctly, when students go to check theirs, it is clear the table is reasonably up-to-date
